# 🔥 Portal Free Fire

### 🚀 [Ver sitio ](https://portal-free-fire.vercel.app/)

Portal no oficial hecho por fans de Free Fire, con herramientas interactivas, calculadoras, guías y datos verificados. Sin promesas de recompensas falsas.

## ¿Qué tiene?

- 🎯 **Sensibilidad & Control** — Generador de sensibilidad por DPI/FPS/gama de teléfono, config para headshot, comparador antes/después
- 💎 **Economía & Diamantes** — Calculadora de diamantes, comparador de recargas, simulador de apertura, bonificaciones
- 🎨 **Identidad & Estilo** — Generador de nombres con símbolos, bios de perfil, clanes y retos
- ⚔️ **Arsenal & Meta** — Comparador de armas y personajes, mascotas, vehículos, tier lists actualizadas
- 📰 **Noticias y guías** — Análisis editorial, calendario de eventos, códigos de canje verificados con fecha
- 🌓 Múltiples temas de color (Azul noche, Verde noche, Dark, Cian noche, Claro día)

## Tecnologías

- [Next.js](https://nextjs.org) 16
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint
